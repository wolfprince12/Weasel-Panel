# Weasel Panel — UI language pack (English / default)
#
# Format:
#   Key = Value
#   · Lines starting with '#' are comments.
#   · Split happens on the FIRST " = " — a value may contain '=' itself.
#   · Use \n for an explicit line break inside a value.
#   · Keys missing here (and in the active language) fall back to the key name,
#     so a typo shows up as "Nav.Apperance" on screen instead of an empty label.
#
# Why plain embedded .txt instead of .resx + satellite assemblies:
#   .resx produces zh-Hans/WeaselPanel.App.resources.dll satellite assemblies.
#   Whether those get bundled into a PublishSingleFile exe is not guaranteed,
#   and a satellite assembly that silently fails to load degrades to English on
#   a Chinese Windows — exactly the "why is it still English?" bug we are
#   fixing here. These .txt files are EmbeddedResource inside the main
#   assembly, so they always travel inside the exe. Verified on the Win11 VM.
#
# Language resolution order (see L10n.ResolveLanguage):
#   1. user choice in %APPDATA%\WeaselPanel\settings.json ("auto" = follow OS)
#   2. CultureInfo.CurrentUICulture (zh-CN → zh-Hans → zh → this file)
#   3. this file
